# Responsibility boundary

## Intent
Keep ownership language inside what evidence supports. Resume Intelligence must not upgrade「参与 / 负责模块」into「主导 / 从0到1 / Owner」without confirmed evidence.

## Rules
1. Map each action verb to a `responsibility_level` ceiling from evidence (参与 ≤ 负责模块 ≤ 主导方案或交付 ≤ 项目负责人).
2. Reject title inflation (student/intern/side project → formal AI PM title) unless evidence + user confirm.
3. Prefer precise scope phrases ("owned X module delivery", "partnered with Y on Z") over absolute ownership claims.
4. Presentation may reorder bullets; it must not rewrite responsibility facts.

## Failure modes
- Draft uses stronger verbs than evidence → audit `must_fix`, block approve.
- User asks to "sound more senior" without new evidence → offer excavation questions, do not invent.
