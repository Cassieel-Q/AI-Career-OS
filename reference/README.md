# Reference material

These folders preserve the source material used while building the final AI Career OS snapshot.

- `aicareeri-interview/` — Nowcoder/company interview research and source cards. The runtime uses the normalized packs under `knowledge/interview_skills/`; this copy is kept for provenance and future refreshes.

Reference documents are not runtime code and should be changed only when their source material is intentionally refreshed.
