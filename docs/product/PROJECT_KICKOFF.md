# AI Career OS — Project Kickoff

**状态**：Product Gate 已通过；Technical Specification 进行中。

## 核心问题

用户不缺资料，缺的是把碎片化、互相冲突的信息转化为适合自己的、有依据的职业决策和下一步行动。

## 一句话定义

> 基于用户真实背景、目标岗位证据和执行进度，持续识别最值得解决的职业差距，并把这些差距转化成下一步可执行行动。

## 核心差异化

1. Evidence Before Advice
2. Multi-JD Aggregation
3. User Profile × Market Profile → Gap
4. NOW / NEXT / NOT NOW
5. Roadmap → Weekly Goal → Daily Tasks
6. Progress → Replanning
7. Dashboard-first
8. Structured Data + Evidence RAG 双轨

## 三人分工

- **Project Owner（你）**：做决定、理解、验收、控制 Scope。
- **ChatGPT**：Product Mentor + Tech Lead，负责 Spec、Review、术语和方案比较。
- **Codex**：Engineering Pair Programmer，只在冻结 Spec 下执行 Task、测试和 Git 操作。

## 核心开发原则

```text
Idea → PRD → Scope Freeze → Tech Spec → Architecture → Data Model → API Contract → AI/RAG Contract → Task Breakdown → Git Bootstrap → Coding → Testing → Review → Deployment
```
