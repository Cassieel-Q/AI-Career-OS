## 人工确认方法

请把 `人工确认` 列填为 `是` / `否`，填好后相关性指标才算得出：

```
相关性 = 人工确认相关的结果数 / 人工已审核的结果数
```

在**没有**任何人工标签之前，该指标一律记为 `UNREVIEWED`，不输出百分比。
