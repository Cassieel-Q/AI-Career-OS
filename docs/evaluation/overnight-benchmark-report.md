## 口径声明（防自欺）

1. **机械评分 ≠ 人工标注**：本报告中的四分类正确率来自规则比对，属可复现的机械评分；
   最终结论以 `annotations/GUIDELINES.md` 规范下的人工标注为准，两者在表格中分开呈现。
2. **单测通过率 ≠ 任务成功率**：后端 pytest 的通过率不在此报告中作为改写质量指标出现。
3. **NOT_RUN 不伪造**：任何因服务未启动 / 模型未配置而未运行的路径，均标注 NOT_RUN。
4. **隐私红线**：数据集校验（validate.py）内置真实手机号 / 身份证号 / 非示例邮箱检测。
