## 运维注意（不是缺陷，但会踩）

- 本机 8000 端口属于另一个项目（CityQuest）。`start-local.cmd` / `start-demo.cmd` 会把后端起在
  **8000**，在这台机器上会撞端口。台式机请用桌面图标（内部走 8100–8105），或设
  `AI_CAREER_API_PORT` 后使用启动器。
- 手工 `npm run build` 若不设 `NEXT_PUBLIC_API_BASE_URL`，前端会退回 **8000**（另一个项目）。
  启动器 `career-app.ps1` / `build-web.ps1` 会自动注入 `http://127.0.0.1:<API 端口>`；
  自己构建时请显式设置该变量。
