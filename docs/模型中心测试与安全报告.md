## 3. SSRF 防护（`validate_endpoint`）

9 组参数化用例 + DNS 解析复测：

- 公网地址强制 HTTPS；解析到内网/回环/保留地址一律拒绝（含 DNS rebinding 场景的 monkeypatch 用例）；
- 本机回环是**受控例外**：允许 `http://127.0.0.1:11434`（Ollama），禁止 1024 以下特权端口与常见本机服务端口（22/3306/5432/6379/9200/27017 等）；
- 拒绝 URL 内嵌凭据；测试请求**手动跟随重定向且逐跳重新校验**（最多 3 跳）。

## 4. 本地 API 访问控制（防恶意网页）

`app/local_access.py`：模型配置全部接口（含读）要求 `Origin` 在白名单内 + 写请求必须带自定义头 `X-AI-Career-Client`；`Sec-Fetch-Site: cross-site` 直接 403。

| 用例 | 结果 |
| --- | --- |
| 恶意来源读取配置 | `test_unauthorized_web_page_cannot_read_or_write` → 403 ✅ |
| 缺客户端头的写请求 | `test_write_without_client_header_is_rejected` → 403 ✅ |
| 本机前端正常读写 | `test_local_ui_can_manage_configs` → 200 ✅ |
| curl 实测恶意 Origin | 403（2026-10-18 实测） ✅ |

## 7. 风险与已知限制

1. GitHub 历史中旧的未脱敏截图已在本分支之前的主线中清除（另见工作日志）；本分支新增截图均为脱敏演示数据。

3. 迁移到其它电脑：DPAPI 密文无法在新机器解密 → 页面会明确报「请重新填写 API Key」，不会静默失败。
