# AI Career OS v0.2 Integrated Dogfood Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one dogfood-ready Job Mission vertical slice that turns a raw JD into grounded What Matters, mission-specific resume preparation, evidence recovery/proof, interview preparation, and outcome capture while preserving the existing v0.1 workflow and v0.2 Resume-to-Proof behavior.

**Architecture:** Add a thin relational Mission layer around the existing TargetJob/ResumeClaim/ProofAction/InterviewSession records. Bounded generated projections stay in JSON columns, while Mission, selections, resume versions/bullets, red-team reports, interview packs, and outcomes have explicit foreign keys. Provider calls use the existing OpenAI-compatible `chat.completions.create` JSON transport, manual `json.loads`, strict Pydantic validation, safe error taxonomy, and no fabricated fallback. Markdown knowledge packs are loaded and ranked deterministically before being supplied to intelligence services.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, Pydantic v2, OpenAI-compatible Chat Completions, PostgreSQL/SQLite test fixtures, Next.js 15, React, TypeScript, Node test runner.
