## 已落地的主链路

- 模拟面试使用 `startInterview` 返回的会话；新会话创建前作废同岗位旧的 ACTIVE 会话。
- 少于三轮时自动生成中文追问；前端保留题目和输入框，错误文案改为中文。
- 恢复证据增加最小内容校验和审计测试文字拦截，并显示接口提示。
- 面试 CTA、准备状态、准备包和最近一次已完成复盘统一读取同一份状态。
- 面经引用读取 `skill_id/source_refs`，从正文解析问法；出题提示强制中文。
- 简历策略去掉英文占位句并去重；已有证据默认接受，无来源的新主张仍需确认。
- Profile 增加姓名、电话、邮箱、城市，并加入迁移和确认页编辑。
- 投递版导出优先读取绑定 Profile，校园经历与项目分开，技能去重，导出前显示检查提示并生成姓名-公司-岗位文件名。
- 简历页先渲染核心数据，再异步读取慢的证明链，避免空状态闪烁。
- 删除或归档岗位后，重新提交同一份 JD 会清理旧任务进度并创建新的任务，不再被历史记录拦截。
- 经历筛选由后端模型结合目标岗位判断四种去向；策略只使用未排除经历，并在模型失败时保留具体事实、避免模板化理由。
- 模拟面试入口固定为“生成问题预览 → 逐题回答 → 评分/复盘 → 补强建议 → 面试记录”；回答框改为整行宽度，侧栏不再显示“需要补强”门槛。
- 目标简历提示词要求保留项目名称、时间、个人动作、方法、结果和奖项等事实，禁止把事实丰富的项目压缩成泛化句。
