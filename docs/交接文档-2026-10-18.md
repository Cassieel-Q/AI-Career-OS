## 2. 环境搭建与启动（Windows）

### 2.1 首次安装

```
install.cmd          # 仓库根目录，一键：venv + 后端依赖 + 前端依赖 + 桌面图标
```

分步等价命令（脚本故障时可手工执行）：

```powershell
python -m venv apps\api\.venv
apps\api\.venv\Scripts\python -m pip install -r apps\api\requirements.txt
cd apps\web && npm install
powershell -NoProfile -ExecutionPolicy Bypass -File create-desktop-shortcut.ps1
```

前置：Python 3.11+（`python` 在 PATH）、Node.js 18+。

### 2.2 日常启动 / 停止

| 方式 | 说明 |
| --- | --- |
| 桌面图标 `AI Career OS` | **推荐**。双击启动并自动打开正确端口页面 |
| 桌面图标 `停止 AI Career OS` | 只停本项目进程，不影响其他项目 |
| `start-career.cmd` / `stop-career.cmd` | 等价的命令行入口 |
| `scripts\local-app\career-app.ps1 -Action start\|restart\|stop` | 底层脚本，`-NoBrowser -Quiet` 可不弹浏览器 |

### 2.3 端口与数据目录

- 后端：`http://127.0.0.1:8100/health`（健康检查）
- 前端：**自动探测端口，当前 3002**。本机 3000/3001 长期被其他项目（findCity 等）占用，端口会漂移，**不要写死端口**。
- 数据目录：`C:\Users\覆水\AppData\Local\AICareerOS`（SQLite 库 + `model_config.json` 模型配置）

### 2.4 生产构建（前端）

`scripts\local-app\build-web.ps1` 会把 `apps/web` 同步到隔离目录 `D:\ai-career-web-build\web` 再构建，避免本机 node_modules 锁死。

> **踩坑（务必记住）**：robocopy 同步可能返回 exit 16（实际一个文件都没复制），表现为"构建成功但页面仍是旧代码"。手工同步时用绝对路径并加 `/XD node_modules`，正常为 exit 1。**构建后必须验证页面文案/行为，不要只看退出码。**

### 2.5 启动方式的重要限制

从"后台任务 / 助手会话"里启动的服务，会随该任务的进程树一起被回收（已实测：保活任务到期时 8100/3002 同时消失，且一次性拉起留不住）。**桌面图标（explorer 启动）不受此限制。** 需要长时间挂机请用桌面图标，不要依赖后台任务托管。

### 2.6 模型配置两种方式（用户视角）

1. 设置页 →「AI 模型」标签：填 Key → 测试连接 → 激活 → 分配给 10 个模块（**主推路径，不需要改 `.env`**）。
2. `.env` 兜底：配置缺失或损坏时自动回退 `.env`，并在状态里标注 `user-broken`。

## 4. 关键设计决策（改动前请先读，避免推翻）

1. **模型配置存在数据库之外**（`<数据目录>/model_config.json`）→ 备份 zip 天然不含密钥。改这条等于把密钥泄漏进备份。
2. **DPAPI 加密存储**：`LocalFree` 来自 `kernel32` 不是 `crypt32`（踩过坑）。解密失败必须报错，**不允许静默降级为明文**。
3. **`requires_key` 在创建/更新时固化进配置**（F1 修复）：换提供商时按预设重算。无密钥服务（Ollama/LM Studio）在"草稿测试 / 已保存测试 / 网关调用"三条路径上都必须一致放行。
4. **本机端口策略（F2）**：回环地址 `127.0.0.1` / `localhost` 任意端口可用（覆盖 LM Studio 1234、vLLM 8000）；**拒绝**自身端口 `8100/8770`（防自指）、敏感端口与特权端口。前后端文案与后端校验必须同步。
5. **CORS 放行回环任意端口**（修复端口漂移整页 `Failed to fetch`）：`allow_origin_regex` + `urlsplit` 取 hostname 判断；`127.0.0.1.evil.com`、局域网 IP、公网非 HTTPS 一律拒绝。
6. **用户配置不可用时回退 `.env`，并在 status 标注 `user-broken`**；换 provider/base_url 而未给新 Key 时标记 `unverified_after_change` 并拒绝使用。
7. **resume 模块的 env 链顺序是 `OPENAI_MODEL` > `OPENAI_RESUME_MODEL`**，与其他 provider 相反，测试已锁定该顺序（别"顺手对齐"）。
8. **测试隔离只 monkeypatch `model_config_service.config_path` 到 tmp_path**（`tests/conftest.py` 的 `isolated_model_config`）。曾尝试清环境变量/数据目录，结果打断 6+ 项依赖真实环境的用例——**只隔离与被测功能直接相关的路径**。
9. **`db.scalars(select(Model.id))` 返回的是 UUID 对象，不能再取 `.id`**（顺顺工具崩溃的修复点）。
