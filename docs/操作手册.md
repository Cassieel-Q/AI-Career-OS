# AI Career OS 操作手册

> 面向第一次拿到这个项目的人：从下载到每天使用的完整流程，包括**桌面图标**和**浏览器扩展**两个最容易困惑的部分。

---

## 一、别人下载后，什么会有、什么不会有？

把仓库下载（clone / Download ZIP）下来时，你拿到的是**源代码和脚本**。以下三样东西**不会自动出现**，各需要一次性设置（都很快）：

| 东西 | 下载后就有吗 | 怎么来的 |
|---|---|---|
| 前后端程序 | ✅ 源码自带 | 跑一次 `install.cmd` 装好依赖 |
| 桌面「AI Career OS / 停止 AI Career OS」两个图标 | ❌ 没有 | `install.cmd` 最后一步自动创建（也可单独运行 `create-desktop-shortcut.ps1`） |
| BOSS 直聘浏览器扩展 | ❌ 没有 | 扩展未上架商店，需在 Edge 里手动加载一次（见第四节） |

数据（简历、岗位、面试记录）保存在本机 `%LOCALAPPDATA%\AICareerOS`，不上传任何服务器。

## 二、首次安装（约 10 分钟，其中大部分是等待）

### 环境要求

- Windows 10 / 11
- [Python 3.11+](https://www.python.org/downloads/)（安装时勾选 *Add python.exe to PATH*）
- [Node.js 18+（LTS）](https://nodejs.org/)
- Microsoft Edge（系统自带即可）

### 方式一：一键安装（推荐）

1. 下载项目到本地（例如 `D:\ai-career`）；
2. **双击项目根目录的 `install.cmd`**。

脚本会依次：检查 Python / Node → 创建虚拟环境并安装后端依赖 → 安装前端依赖 → 在桌面创建启动/停止两个快捷方式。装过的部分会自动跳过，重复运行安全。

### 方式二：手动安装

```bat
cd apps\api
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

cd ..\web
npm install
```

再运行一次根目录的 `create-desktop-shortcut.ps1` 创建桌面图标。

### 配置模型（必需）

在项目根目录创建 `.env` 文件（不会被上传到 Git）：

```env
OPENAI_API_KEY=你的密钥
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

支持任意 OpenAI 兼容端点（DeepSeek、通义、Moonshot 等）。没有配置模型时系统会降级为本地规则，功能可用但智能生成（改写、参考答案）不可用。

> 可选：简历 PDF 预览/导出依赖 [Typst](https://typst.app/)，下载 `typst-x86_64-pc-windows-msvc.zip` 解压到 `.runtime\typst-0.15.1\`。缺失只影响 PDF 导出。

## 三、每天怎么用：桌面图标

安装完成后，桌面上会有两个图标：

| 图标 | 作用 |
|---|---|
| **AI Career OS** | 双击启动。自动拉起后端 API + 前端，并用 **Edge 独立应用窗口**（无地址栏、无标签页，外观等同桌面软件）打开工作台。启动过程无黑窗。 |
| **停止 AI Career OS** | 双击停止本项目全部服务，不影响电脑上其他程序。 |

- 命令行等价方式：`powershell -File scripts\local-app\career-app.ps1 -Action start`（或 `-Action stop`）。
- 如果页面看起来是旧版或空白，在窗口里按 **Ctrl+F5** 强制刷新。
- 图标丢了/想重建：重新运行 `create-desktop-shortcut.ps1` 即可，会覆盖更新。

## 四、浏览器扩展：BOSS 直聘岗位一键采集

### 为什么需要手动加载？

扩展没有上架 Edge 商店（也不会上架——它只在本机工作），所以 Edge 不会自动安装。**需要手动加载一次**，之后一直有效，直到你手动移除或项目更新了扩展代码。

### 加载步骤（一次性）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车；
2. 打开左下角的 **「开发人员模式」** 开关；
3. 点击 **「加载解压缩的扩展」**；
4. 选择项目里的 **`apps\extension`** 文件夹；
5. 加载成功后，工具栏出现 AI Career OS 扩展图标，显示「扩展版本 v1.3.4」。

### 配对（一次性）

扩展需要和本机后端配对才能导入岗位：

1. 先确保 AI Career OS 已启动（桌面图标启动即可）；
2. 点击扩展图标：如果显示「已配对」直接用；如果显示未配对，把 `%LOCALAPPDATA%\AICareerOS\extension.token` 文件里的令牌粘进配对框（扩展弹窗里有指引）。

### 使用流程

1. 在 BOSS 直聘打开一个感兴趣的岗位详情页；
2. 点浏览器工具栏的 AI Career OS 扩展图标 → 点「采集此岗位」；
3. 扩展自动提取职位描述（自动清理页面水印噪声）并保存；
4. 默认勾选「导入后直接进入工作台」——保存后岗位直接出现在 AI Career OS 的岗位库里，回到应用点「匹配分析」即可开始优化。

> ⚠️ 合规提醒：扩展只做「你手动点一下、采集你正在看的这一个岗位」。它不会自动打招呼、不会批量投递、不会绕过 BOSS 的任何限制。
>
> 项目更新后若扩展有新版本：在 `edge://extensions` 里找到本扩展，点「重新加载」即可。

## 五、核心使用路径

1. **简历中心**（侧栏「简历」）：上传一次 PDF 简历，之后所有岗位共用，不需要重复上传；
2. **导入岗位**（侧栏「岗位」）：① 手动粘贴 JD / ② 扩展采集，保存进岗位库；
3. **匹配分析**：岗位库点「匹配分析」→ 看匹配度、为什么匹配 / 哪里不匹配；
4. **简历优化**：岗位档案第 02 步，AI 按 **STAR / STAR-C / 能力证据链** 框架给出每段经历的定向改写，逐条采纳；
5. **模拟面试**：第 03 步，按宝洁八大问 + 岗位 JD 出题，逐题作答、评分、复盘；
6. **面试记录**：录真实面试的题目和回答——这些题目会自动回流进题库，面得越多题库越准。

## 六、数据与隐私

- 所有数据存在本机：`%LOCALAPPDATA%\AICareerOS`（SQLite 数据库 + 上传的简历文件 + 运行日志）；
- 换电脑 / 备份：拷贝这个目录即可；
- 发出去的请求只有两类：你配置的模型 API（用于生成）、BOSS 页面（仅扩展采集时读取你打开的页面）。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 双击图标没反应 / 一闪而过 | 右键图标 → 属性，确认「目标」指向项目实际路径；把项目整个目录移动过位置的话，重建快捷方式（运行 `create-desktop-shortcut.ps1`） |
| 启动报「找不到 node.exe」 | 安装 Node.js LTS 后重新运行 `install.cmd` |
| 启动报「找不到 Next.js 入口」 | 在 `apps\web` 里执行 `npm install` |
| 页面空白或显示旧版 | Ctrl+F5 强刷 |
| 智能生成报错 / 内容变简单 | 检查 `.env` 里的模型配置；模型不可用时系统自动降级为本地规则，不会白屏 |
| 扩展显示「未配对」/ 401 | 确认应用已启动，然后按第四节重新粘贴令牌 |
| 想彻底重装 | 停止服务 → 删除 `apps\api\.venv`、`apps\web\node_modules` → 重新运行 `install.cmd`（数据在 `%LOCALAPPDATA%\AICareerOS`，不受影响） |
